# SAPI Bomberman 1.0.0 (2026-10-07)

Poznámky k vydání na GitHubu (Release `v1.0.0`, příloha `SAPI-Bomberman-1.0.0.zip`).

Bomberman (Hudson Soft 1983, verze pro Sharp MZ-700) pro Tesla SAPI-1, sestavu „V“
(JPR-1V, RAM-1V, CGA-1V, MPH-1V), jako BOMBER.COM pro CP/M.

- Stejná hra jako na MZ-700, barevná grafika CGA-1V, zvuk YM3812.
- Pevný snímek 60,8 ms i při procesoru 2 MHz, i při výbuchu pěti bomb najednou.
- Joystick Atari (pohyb a bomba zároveň), klávesnice Consul 262.3 i EKL-1, ESC zpět do CP/M.

Zip obsahuje BOMBER.COM, bomber.hex (Intel HEX od 0100h, pro emulátor), README a CHANGELOG.
Spuštění v SAPIemu: sestava sapi1v.sapi, boot 1, Soubor → Nahrát program do paměti → bomber.hex,
SAVE 42 BOMBER.COM, BOMBER.

Vyzkoušeno v SAPIemu 0.3.0 alpha, na skutečném SAPI-1 zatím ne.

English: Hudson Soft's Bomberman (1983, Sharp MZ-700) ported to the Tesla SAPI-1 "V" boards
(CGA-1V colour graphics, MPH-1V YM3812 sound and joystick), CP/M. Runs at 2 MHz too.
