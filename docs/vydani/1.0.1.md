# SAPI Bomberman 1.0.1 (2026-10-16)

Poznámky k vydání na GitHubu (Release `v1.0.1`, příloha `SAPI-Bomberman-1.0.1.zip`).

Opravná verze Bombermana (Hudson Soft 1983, verze pro Sharp MZ-700) pro Tesla SAPI-1, sestavu „V“
(JPR-1V, RAM-1V, CGA-1V, MPH-1V), jako BOMBER.COM pro CP/M.

- Šipky z klávesnice (Consul 262.3 i EKL-1) už nenechávají hráče v půlce políčka. Šipka jiného směru během
  kroku počká, až hráč dojde na celé políčko. Dřív rozdělaný krok zahodila a pak se špatně zatáčelo.
- Hra je jinak stejná jako 1.0.0 (ověřeno v emulátoru porovnáním obrazovek v každém snímku).
- Spuštění v SAPIemu 0.3.0 alpha: při startu sestavy zvolit 3. Volba 1 se v této verzi emulátoru zasekne.

Zip obsahuje BOMBER.COM, bomber.hex (Intel HEX od 0100h, pro emulátor), README a CHANGELOG.
Spuštění v SAPIemu: sestava sapi1v.sapi, boot 3, Soubor → Nahrát program do paměti → bomber.hex,
SAVE 42 BOMBER.COM, BOMBER.

Ověřeno na skutečném SAPI-1 V (1.0.0) a v SAPIemu 0.3.0 alpha.

English: bug fix release. Cursor keys no longer leave the player half way in a cell (a key of another
direction waits for the whole cell). In SAPIemu 0.3.0 alpha boot the sapi1v machine with choice 3.
